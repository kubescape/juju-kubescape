# Security

The Kubescape Juju charm is deprecated and is being retired. Existing users
should plan a migration using the
[Kubescape Operator installation instructions](https://kubescape.io/docs/install-operator/).
The deprecation notice does not remediate known vulnerabilities in published
charms or existing deployments.

For vulnerability reporting, follow the
[centralized SECURITY.md](https://github.com/kubescape/project-governance/blob/main/SECURITY.md).
